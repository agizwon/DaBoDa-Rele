# MyPcTools : DaBoDa (다보다)

이미지·사진·PDF·3D·CAD·압축 파일을 한 프로그램으로 보는 다목적 뷰어입니다. MyPcTools 시리즈 1호.

이 저장소는 **배포본을 내려받는 곳**입니다. 프로그램의 업데이트 확인도 여기를 봅니다.

- 내려받기 : 오른쪽의 **Releases** 에서 최신판의 파일을 받습니다.
  - `DaBoDa_v…_setup.exe` : 설치판(권장). 실행하면 설치됩니다. 업데이트를 받을 수 있습니다.
  - `DaBoDa_v…_portable.zip` : 포터블판. 설치 없이 풀어서 씁니다(USB 에 넣어 다닐 때).
  - `DaBoDa_v…_setup.zip` : 설치판을 폴더째 묶은 것. 인스톨러 실행이 막힌 PC 용입니다.
  - `DaBoDa_v…_arm64-v8a_debug.apk` : 안드로이드 폰용. PC 의 DaBoDa 에서 "안드로이드 폰에 설치" 로 넣는 것이 가장 쉽습니다.
- 사용 환경 : Windows 64비트
- 업데이트 : 0.1.7 부터 새 판이 나오면 프로그램 위쪽에 "업데이트" 버튼이 나타납니다. 바뀐 점을 먼저 보고 [지금 업데이트]·[나중에]·[이 버전 건너뛰기] 중에서 고를 수 있습니다.
- 볼 수 있는 것 : 이미지·사진(HEIC 포함), PDF, 3D(STEP·FreeCAD 문서), 도면(DXF·DWG·KiCad), 압축 파일
  - STEP·FreeCAD 문서는 PC 에 [FreeCAD](https://www.freecad.org/) 가 있어야 합니다.
  - DWG 는 무료 변환기 [ODA File Converter](https://www.opendesign.com/guestfiles/oda_file_converter) 가 있어야 합니다. DaBoDa 에는 들어 있지 않으니 따로 설치합니다.
- 버전 : `주.부.수` (예: 0.1.7)

## English

DaBoDa is a multi-purpose viewer that opens images, photos, PDF, 3D, CAD and archive files in one program. It is the first tool in the MyPcTools series. "DaBoDa" (다보다) means "see everything" in Korean.

This repository is **where you download the releases**. The program also checks here for updates.

- Download : open **Releases** on the right and get a file from the latest release.
  - `DaBoDa_v…_setup.exe` : installer (recommended). Run it to install. It can receive updates.
  - `DaBoDa_v…_portable.zip` : portable version. Unzip and run without installing (for a USB drive).
  - `DaBoDa_v…_setup.zip` : the installed files as a folder, for PCs where running the installer is blocked.
  - `DaBoDa_v…_arm64-v8a_debug.apk` : for Android phones. The easiest way is "Install on Android phone" inside DaBoDa on the PC.
- Requirements : 64-bit Windows
- Updates : from version 0.1.7, an "Update" button appears at the top of the program when a new version is available. You can read what changed first, then choose [Update now], [Later] or [Skip this version].
- What it opens : images and photos (including HEIC), PDF, 3D (STEP, FreeCAD documents), drawings (DXF, DWG, KiCad), archives
  - STEP and FreeCAD documents need [FreeCAD](https://www.freecad.org/) installed on the PC.
  - DWG needs the free [ODA File Converter](https://www.opendesign.com/guestfiles/oda_file_converter). It is not included in DaBoDa, so install it separately.
- Version : `major.minor.patch` (for example 0.1.7)
